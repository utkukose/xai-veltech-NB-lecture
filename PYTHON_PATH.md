## How to practise

Type the code instead of copying it, run each cell and change one value at a time to see what happens. When an error appears, read its last line first: It names the problem and the line. Try every exercise before opening the reference solution, and compare the two afterwards.

## Beyond the course

The official Python tutorial at <https://docs.python.org/3/tutorial/> covers the language in depth. The user guides of NumPy, pandas, Matplotlib and scikit-learn are the best next step for data work.
