# Datasets

Every dataset of the course is either bundled with a standard Python library or generated inside the notebook with a fixed random seed, so no download or upload is needed.

| Dataset | Source | Used on | Licence or origin |
|---|---|---|---|
| Breast Cancer Wisconsin (Diagnostic) | UCI Machine Learning Repository, bundled with scikit-learn | Days 1 to 5 | CC BY 4.0, Wolberg and colleagues |
| Synthetic credit scoring | Generated in the notebooks with a fixed seed | Days 4 and 5 | Created for the course, with an injected proxy bias |
| Synthetic lesion images | Generated in the notebooks with a fixed seed | Days 1, 3 and 4 | Created for the course, with a planted shortcut |
| Synthetic product reviews | Generated in the notebooks with a fixed seed | Days 3 and 5 | Created for the course, with a spurious token |
| Synthetic machine telemetry | Generated in the notebooks with a fixed seed | Day 5 | Created for the course, for predictive maintenance |
